Built for your computers.

Across is an original desktop implementation. This first release is an engineering preview.

What this build includes

Mac and Windows native input helpers; TLS 1.3 pairing with certificate pinning and explicit approval; up to ten clients; LAN host discovery; adjustable computer layout; mouse, keyboard, buttons and scroll relay; text, rich-text and image clipboard; file sending with integrity checks; cursor lock, keyboard broadcast, profiles, hotkeys, dimming and keep-awake.

Validation status

Mac helper compiles and display detection works. Live input needs Accessibility permission. Windows helper and physical Mac-to-Windows operation need testing on a Windows computer.

Feature gaps being tracked

Native Finder/Explorer file drag-and-drop and file paste; Windows sign-in/UAC secure desktop and Ctrl+Alt+Del; per-keyboard hardware routing and local macros; individual-monitor exclusions and Hop Keys; automatic reconnection, update/rollback; restart, sleep, shutdown and unlock synchronization. They are not implemented in this build.
