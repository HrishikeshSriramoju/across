Across for Mac

Native input helper, screen-edge handoff, and a workspace that stays on your local network.

Download for Mac ↓
.dmg · arm64 · 0.1.4macOS 13+ helper*
Install & verify
  1. Open the disk image. Drag the entire Across app into Applications.
  2. Open Across from Applications. Keep Across Input inside the app.
  3. Choose Enable input and approve Across in macOS Privacy & Security when asked. Allow Local Network access for discovery.

*Apple Silicon build only. The packaged Electron runtime must also support your installed macOS. Intel Mac is not included.

This is a locally development-signed, non-notarized preview. It does not have an Apple Developer ID certificate. Do not disable system security protections.

Across for Windows

Share in the background. Minimize or close the window to the tray, and keep your desk connected.

Download for Windows ↓
.zip · x64 · 0.1.5Windows PowerShell 5.1
Install & verify
  1. Quit the older Across using its tray menu. Extract the entire ZIP into a new folder.
  2. Run Across.exe. Keep resources and all sibling files beside it.
  3. Allow Across through Windows Firewall for your trusted Private network when asked. Never turn off the firewall.
  4. Enable input and reconnect. Existing Mac 0.1.4 and saved pairings are compatible.
  5. Minimize or close the window to keep sharing. Click the lime Across icon in the notification area (possibly under hidden icons) to reopen. Choose Quit Across there to stop.

This preview has no publisher signing certificate. Windows may show a security prompt. Do not disable Defender or other protections. Physical Windows background behavior still requires testing on your own computer.

Release notes ↗
THREE STEPS. ONE WORKSPACE.

Get connected.

  1. 01

    Open on both

    Use the same trusted Wi-Fi or local network. Both desktop apps need to be running.

  2. 02

    Pair once

    Choose Host workspace on the computer with your keyboard and mouse. Connect from Nearby computers on the other, enter the code, and approve the request. Future connections can reconnect without a code.

  3. 03

    Arrange & move

    Enable input on both. Drag the remote computer beside yours in the desk map, then move across the shared edge. Ctrl+Alt+Esc always returns control locally.

Your shortcuts, your way.

In Preferences, choose Record and press a combination. Release, Switch computer, and Cursor lock can each have their own shortcut.

Return locally
Ctrl + Alt + Esc
Switch computer
Ctrl + Alt + Space
Cursor lock
Ctrl + Alt + L
On Mac, Alt means Option. OS-reserved shortcuts may still be intercepted.

A preview, not a promise.

Native input, opt-in clipboard sync, explicit file sending, profiles, discovery, and remembered devices are implemented. Live cross-platform behavior is still being validated.

Native file drag-and-drop, Windows sign-in/UAC control, automatic app updates, and Linux packages are not included. The web demo is illustrative, not the desktop app.
